GOBBLER POS Backup

GOBBLER POS Backup is a private, single-user tool. It copies encrypted backups of its owner's own point-of-sale database into a folder in the owner's own Google Drive, once a day, so that the owner can recover the data if the primary database is lost.

What the app does

  • Runs on a schedule in the owner's private GitHub repository.
  • Encrypts each backup before it leaves the GitHub runner, so the files stored in Google Drive are unreadable without the owner's passphrase.
  • Uploads the encrypted files to one folder in the owner's Google Drive, checks them, and removes old backups according to a retention rule.

Google access

The app requests a single Google permission, https://www.googleapis.com/auth/drive.file. This permission allows the app to see and change only the files the app itself created. It cannot see any other file in the owner's Google Drive.

Who can use it

This is not a public service. It has one user, its owner, who authorises it with their own Google account. Nobody else is asked to sign in.
