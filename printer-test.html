Printer test

For a USB receipt printer (80 mm, ESC/POS) attached to an Android phone with an OTG adapter. This page only sends printer commands to the device you pick. It collects, stores and sends nothing anywhere.

  1. Open this page in Chrome on Android, not inside another app.
  2. Switch the printer on, load paper, and connect it with the OTG adapter and a data cable.
  3. Tap button 1. Choose the printer in the list and allow access.
  4. If anything fails, screenshot the green log below and send it.
